# Student Management System (React Practical Exam)

This project is a Student Management System built with React, Redux Toolkit, React Router, Tailwind CSS, and JSON Server.

## Features

- User authentication (demo credentials)
- Protected routes with `PrivateRoute`
- Student CRUD operations
- Sorting by name or roll number
- Filtering by class
- Responsive Tailwind-styled UI

## Demo Login

## Run Project

1. Install dependencies

```bash
npm install
```

2. Start JSON Server backend

```bash
npm run server
```

3. In another terminal, start frontend

```bash
npm run dev
```

## API

- Base URL: `http://localhost:3001`
- Students route: `http://localhost:3001/students`
